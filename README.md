# Tweet Card Component - STEM 112

A custom, responsive HTML and CSS Tweet Embed component designed for section **STEM 112 | A.Y. '24 - '25**. It features realistic Twitter haha custom interactive controls, dynamic badges, and icon support.

---

## Features

* **Authentic UI Design:** Styled to match Twitter post cards using Google Fonts (`Poppins` and `Plus Jakarta Sans`) and CSS custom properties.
* **Interactive Elements:** Pure CSS/HTML checkbox-driven Like button with dynamic heart icon toggling.
* **Icon Integration:** Utilizes Google Material Icons and Font Awesome (v6.4.0) for standard social action icons.
* **Custom Profile Assets:** Embedded avatar artwork (`STM112_optimized.png`) and custom export assets (`Tweet Post.png`).
